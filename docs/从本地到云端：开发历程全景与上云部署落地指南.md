## 第一部分：全系统开发历程全景回顾 (Milestones 1 ~ 8)

### 一、 核心设计哲学与系统原则
1. **以极高摩擦力消灭破窗**：一次违规需要不可逆的成本，杜绝灰色妥协与心智内耗；
2. **不篡改历史**：无论是放弃还是免责，客观沉淀真实心流秒数与履历，不掩盖自控伤疤；
3. **主链连胜神圣感**：将日常专注凝练为主链连续胜场（Streak），失败清零，建立对启动专注的敬畏心；
4. **全系统无 Emoji 极客质感**：100% 杜绝泛滥、幼稚的 Emoji 表情，全面拥抱纯 CSS 状态微点、几何徽标与 SVG 矢量设计；
5. **沙盒化防震荡设计**：编辑树草稿在前端内存沙盒中修改，未确认保存绝不污染数据库底表；
6. **移动优先（Mobile First）原生手感**：兼顾宽屏桌面沉浸感与移动端触控大面积、单手可达性。

### 三、 各模块核心功能达成清单

#### 1. 神圣座位（Sacred Seat）
- **心流时钟与倒计时**：支持标准番茄心流（60m/自定义）、顺水推舟正向计时（超额自动累加）、动态线性时延预约链（+5m, +10m, +15m, +30m 田字格触控块）；
- **30 秒后悔药机制**：启动 30 秒内免责退出，主链连胜完整保全，消灭面对极大心理阻力时的启动恐惧；
- **全周期自控档案与热力图**：52 周滚动日历投入热力图（GitHub 级）、流水明细分段器、指标统计面板（总时长、完成率、主链连胜）；
- **主链连胜持久化**：以实时数据库结算为准，防止断签造假。

#### 2. 国策画布中枢（Focus Canvas）
- **Vue Flow 拓扑排布**：支持国策卡片、分组外框容器、正交步进连线（SmoothStep / Orthogonal）；
- **沙盒编辑态与展示态分离**：展示模式单击点亮/熄灭；编辑模式两步桩连线（Click-to-Connect）、卡片自由拖动布局、分组自动吸附；
- **排版安全审计**：删除节点或外框时，自动计算受影响的级联依赖连线，弹出集中审计弹窗二次确认；
- **移动端定制控制条**：左侧贴边放置【演化快照】版本徽标，右侧放置【居中全景】与【刷新】，利用 `justify-content: space-between` 留出开阔视距。

#### 3. 国策列表管理（Focus List）
- **类 Excel 复合排序**：支持多列联动（状态 > 代码 > 级别 > 触发时间），并创新实现“时间沉底算法”（未设置时间的独立国策自动沉底至全天候下方）；
- **单层滚动与表头精准对齐**：彻底消除双层横向滚动条脱节问题，外层统一采用 840px 视口单向水平滑动；
- **实时检索与场景分组过滤**：支持按代码、名称、场景或分组即时过滤。

#### 4. 下必为例判例法典（Case Law）
- **终身放行与绝对禁止裁决库**：为灰色边缘行为（如“中途起身接水”、“查阅开发文档”）提供不可逆的司法判例；
- **移动端单手交互优化**：
  - **第 1 行**：筛选胶囊 `[全部] [允许] [禁止]` 靠右对齐；
  - **第 2 行**：`[导出]`、`[导入]` 与主行动项 `[+ 添加判例]` 三按钮等比均分整行宽度，触控反馈舒适。

#### 5. 演化中枢与数据迁移（Evolution & Migration）
- **5 槽位环形快照队列**：锁定最近 5 个版本，写入自动推进覆盖，防止频繁更改国策树导致的策略震荡；
- **系统数据中枢（全量迁移）**：支持将国策树、神圣座位参数、流水记录、判例法典一键导出为单个 JSON 镜像包，支持换机零损耗恢复。

#### 6. 移动端全场景体验打磨（Mobile Experience）
- **视口适配**：适配从窄屏小屏（iPhone SE 3，375x667）到现代大屏（红米 K60 至尊版，393x873 等高密屏）；
- **底部原生 Tab 导航栏**：iOS / Android 原生 App 级磨砂底部栏，触控带有微缩与微光反馈；
- **字体与排版一致性**：移除非英文字符上的 `.font-mono`，统一现代无衬线中文字形；
- **无头浏览器验证**：多轮 Headless 自动化视觉审查与截图存档，确保零裁切、零挤压、零溢出。

### 阶段一：基础设施采购与网络准备 (Infrastructure Setup)

#### 1. 云服务器选型建议
- **推荐提供商**：腾讯云 / 阿里云 / 华为云（国内节点需备案，延迟低；香港/海外免备案，即开即用）；
- **配置规格推荐**：
  - **轻量应用服务器（Lighthouse / ECS）**：2核 CPU、2G 内存、3M~4M 峰值带宽、系统盘 40G~60G SSD；
  - **费用参考**：新用户首年约 60 ~ 120 元；
  - **操作系统**：推荐选择 **Ubuntu 22.04 LTS 或 24.04 LTS**（社区生态最成熟，软件包最新，维护省心）。

#### 2. 域名购买与 DNS 解析
- **购买域名**：在腾讯云/阿里云注册一个简短易记的个性域名（如 `.com`、`.top`、`.cc`，一年约 10~30 元）；
- **备案考量**：
  - **国内大陆服务器**：需完成工信部 ICP 备案（约需 3~10 个工作日，全程手机 App 刷脸即可完成）；
  - **香港/海外服务器**：解析即生效，无需备案，适合立即上线体验。
- **DNS 解析配置**：
  - 在云解析控制台添加两条 `A 记录`：
    - 主机记录 `@` -> 指向您的服务器公网 IP；
    - 主机记录 `www` -> 指向您的服务器公网 IP。

#### 3. SSL/TLS HTTPS 安全证书
- 公网环境必须开启 HTTPS，否则手机浏览器会提示“不安全”，且 PWA 与浏览器某些触控/全屏 API 会被禁用；
- 使用免费开源的 **Certbot (Let's Encrypt)** 自动化申请与续期，每 90 天自动静默续签，永久免费。

### 阶段二：系统安全加固与防爬虫鉴权体系 (Security & Anti-Scraper)

> **关键问题**：当前系统为本地单机版，所有 API（`/api/*`）均为公开无鉴权状态。一旦直接部署到公网，任何扫描器都能读取或篡改您的专注历史与国策树！必须在部署前建立鉴权防线。

#### 1. 登录认证与 Token 鉴权（Authentication）
- **轻量单用户私有云模式**：
  - 在服务器环境变量中设置管理员密码散列值（`ADMIN_PASSWORD_HASH`）；
  - 增加 `/api/auth/login` 接口与简洁优雅的登录页面；
  - 密码比对采用安全加盐哈希库 `bcrypt`；
  - 登录成功颁发带有效期的 **JWT (JSON Web Token)**，前端存入安全的 `HttpOnly Cookie` 或 Pinia 本地持久化；
  - 后端增加统一鉴权中间件 `authenticateToken`：所有非登录接口均需验证 Token，拦截全部非法请求（返回 401）。

#### 2. 防爆破与防爬虫攻击机制（Anti-Brute-Force & Rate Limiting）
- **接口速率限制（Rate Limiting）**：
  - 引入 `express-rate-limit` 中间件；
  - 登录接口限制：同一 IP 每 15 分钟最多尝试 5 次，超出直接锁定 30 分钟，抵御撞库与字典爆破；
  - 通用 API 限制：同一 IP 每分钟最多 120 次请求，超出拦截，防止爬虫抓取接口。
- **HTTP 安全标头加固**：
  - 引入 `helmet` 中间件；
  - 开启 `X-Content-Type-Options: nosniff`，禁止 MIME 类型嗅探；
  - 开启 `X-Frame-Options: DENY`，防止 Clickjacking 劫持；
  - 开启 `Strict-Transport-Security (HSTS)`，全站强制走 HTTPS 加密。
- **CORS 跨域策略收拢**：
  - 将开发环境的 `cors()` 全开放，改为严格校验只允许自己的生产域名访问。

#### 3. 服务器防火墙与 SSH 安全加固
- **UFW 防火墙策略**：
  - 仅开放必要端口：`80`（HTTP），`443`（HTTPS），以及一个**非标准 SSH 端口**（例如将默认 22 端口改为 22222，直接避开 99% 的全网端口扫描爬虫）；
- **Fail2ban 安装**：
  - 监控服务器 SSH 与 Web 日志，任何 IP 在 5 分钟内认证失败超过 3 次，系统底层直接将其加入 iptables 黑名单封禁 24 小时。

### 阶段三：云端生产环境部署架构 (Production Architecture)

云端采用现代 Web 经典工业级架构：**Nginx (静态托管+反代网关) + Node.js (PM2 守护) + SQLite (本地嵌入式)**。

```
              用户手机 / 电脑浏览器 (HTTPS)
                            │
                            ▼
              ┌───────────────────────────┐
              │    Nginx (端口 80 / 443)   │
              │  - 静态资源 Gzip 缓存     │
              │  - SSL 证书安全卸载       │
              └─────────────┬─────────────┘
                            │
              ┌─────────────┴─────────────┐
              ▼                           ▼
      【前端静态文件】              【反向代理 /api】
      /var/www/sacred-focus/dist         │
                                         ▼
                             ┌─────────────────────────┐
                             │ PM2 进程守护 (端口 3000) │
                             │  - 后端 Express 服务    │
                             │  - SQLite 事务数据库    │
                             └─────────────────────────┘
```

#### 1. 前端构建与 Nginx 托管
- 本地或服务器执行 `npm run build`，产物输出至 `frontend/dist`；
- Nginx 配置示例：
  ```nginx
  server {
      listen 80;
      server_name your-domain.com;
      return 301 https://$host$request_uri; # 强制 HTTPS
  }

  server {
      listen 443 ssl http2;
      server_name your-domain.com;

      ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
      ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;

      # 前端静态单页应用托管
      location / {
          root /var/www/sacred-focus/dist;
          index index.html;
          try_files $uri $uri/ /index.html; # 保证前端路由无缝工作
      }

      # 后端 API 反向代理
      location /api/ {
          proxy_pass http://127.0.0.1:3000/api/;
          proxy_http_version 1.1;
          proxy_set_header Upgrade $http_upgrade;
          proxy_set_header Connection 'upgrade';
          proxy_set_header Host $host;
          proxy_set_header X-Real-IP $remote_addr;
          proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
          proxy_set_header X-Forwarded-Proto $scheme;
      }
  }
  ```

#### 2. 后端服务的 PM2 守护
- 安装 PM2：`npm install -g pm2`；
- 启动并开机自启：
  ```bash
  pm2 start dist/server.js --name "sacred-focus-api"
  pm2 startup
  pm2 save
  ```
- 自动管理进程崩溃重启、内存超限监控、系统重启拉起。

#### 3. 数据库持久化与每日冷备策略
- SQLite 优势：纯单文件数据库，无须额外维护 MySQL/PostgreSQL 繁重服务，低内存占用；
- 编写每日自动备份脚本 `/opt/scripts/backup-db.sh`：
  ```bash
  #!/bin/bash
  DATE=$(date +%Y%m%d_%H%M%S)
  sqlite3 /var/www/sacred-focus/backend/sacred_focus.db ".backup '/var/backups/sacred_focus_${DATE}.db'"
  # 仅保留最近 30 天备份
  find /var/backups/ -name "sacred_focus_*.db" -mtime +30 -delete
  ```
- 配置 Linux `crontab` 每天凌晨 03:30 自动执行一次。
